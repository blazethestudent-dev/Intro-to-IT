Topic 02

Networking & security

Learn how devices connect and how to protect your information.

How a network works

A network connects devices so they can exchange data and share resources. A home network may connect a laptop, phone, and printer. The internet connects networks around the world.

  1. Connect: a device joins a local network using Wi-Fi or an Ethernet cable.
  2. Address: an IP address identifies a network interface for communication.
  3. Route: a router forwards traffic between networks.
  4. Resolve: DNS helps translate names such as example.com into IP addresses.

Local connection versus internet access

Being connected to Wi-Fi does not guarantee access to the internet. A device may reach the local router while the router’s connection to the internet is unavailable.

Local network (LAN)

A network within a limited area, such as a home, classroom, or office.

Router

A device that forwards packets between networks. Home routers often also include Wi-Fi access point functions.

Basic security habits

Cybersecurity protects systems and information against unauthorized access, disruption, and other threats.

  • Use strong, unique passwords and a password manager.
  • Enable multifactor authentication when it is available.
  • Install software and operating system updates.
  • Check unexpected links, attachments, and requests for information.
  • Back up important files and check that you can restore them.

Recognize phishing

An unexpected message claims your school account will be closed unless you sign in immediately. Instead of using the message’s link, open the school’s official website directly and verify the request.

Learning references: Cloudflare: DNS and CISA: Secure Our World.

Separate local and name-resolution problems

Start by checking whether the device has a connection and a valid IP configuration. A gateway connectivity test helps investigate the local path. If an IP address is reachable but a hostname fails, investigate DNS. A failed ping alone does not prove a host is offline because some systems block these requests.
