Project purpose

This project explains the basics of IT. It uses examples like saving a document and connecting to a home network to explain the topics.

The topics include hardware, software, networking, and security. There is also a page with key terms and a page with learning resources.

How the website is organized

The website has six pages. Each page uses the same CSS file and menu. CSS Grid places some sections next to each other.

This is a class project for IT 3203: Introduction to Web Development.
