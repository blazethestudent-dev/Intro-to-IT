Topic 01

Hardware & software

Hardware is the physical equipment. Software tells it what to do.

What is hardware?

Hardware includes the physical parts of a computer, such as the processor, memory, storage drive, keyboard, and monitor. Each component has a different job.

Common computer components
Component Main purpose Everyday example
CPU Executes program instructions. Performs calculations in a spreadsheet.
RAM Temporarily holds data used by running programs. Keeps an open document available while you edit.
SSD Stores files even when power is off. Keeps your saved photos and applications.
Input devices Send information into a computer. A keyboard, mouse, or microphone.
Output devices Present information from a computer. A monitor, printer, or speaker.

What is software?

Software consists of programs and instructions that tell hardware what to do. System software manages the computer, while application software helps users perform specific tasks.

System software

Windows, macOS, and Linux are operating systems. An operating system manages memory, files, devices, and application access to resources.

Application software

Web browsers, word processors, and games are applications. They use services provided by the operating system.

Example: writing a paper

Your keyboard provides input, the CPU processes instructions, RAM holds active work, and the screen displays the document. Saving writes the document to storage. Unsaved changes in RAM can be lost when power is interrupted.
