Quick reference

Seven key concepts

Seven terms that help explain the basics of IT.

Key terms

1. Hardware
The physical equipment in a computer system, including the CPU, RAM, storage, and peripheral devices.
2. Software
Programs and instructions that run on a computer. Examples include operating systems, browsers, and document editors.
3. Operating system
System software that manages hardware resources and provides services for applications and users.
4. Network
A group of connected devices that communicate and share resources.
5. IP address
A numerical address used to identify a network interface and help deliver data. Addresses can change, and private addresses can be reused on separate networks.
6. Cybersecurity
The practice of protecting computers, networks, and information from threats such as unauthorized access and disruption.
7. Cloud computing
Accessing computing resources, such as storage or processing, over a network on demand. An example is storing files in an online drive.

How these terms connect

A laptop’s hardware runs an operating system and other software. It joins a network, uses an IP address to communicate, and accesses cloud computing services. Cybersecurity helps protect those activities.

Three more useful terms

DNS
A service that helps resolve domain names to IP addresses.
Multifactor authentication
Authentication using different kinds of evidence, such as a password and a security key.
Backup
A separate copy of data that can be restored after loss or damage. Test restores to check that the copy is usable.
