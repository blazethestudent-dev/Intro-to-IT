References & resources

Sources used for this project and links for learning more.

Reading list

  • GCFGlobal — Computer Basics

    Lessons on computer components, operating systems, applications, and basic computer use. Supports the hardware and software topic.

  • Cloudflare Learning Center — What is DNS?

    An explanation of how domain names are resolved into IP addresses. Supports the networking topic.

  • CISA — Secure Our World

    Security guidance on phishing, strong passwords, multifactor authentication, and software updates.

  • NIST — The NIST Definition of Cloud Computing

    NIST Special Publication 800-145, by Peter Mell and Timothy Grance (2011). A formal reference for the cloud computing concept.

A simple study approach

  1. Read the hardware and software topic.
  2. Explain the difference between RAM and storage in your own words.
  3. Read the networking topic and identify your home network devices.
  4. Review the seven key concepts.
